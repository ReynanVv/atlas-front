# Atlas Frontend

Frontend oficial do Atlas, plataforma que conecta treinadores e alunos para prescrição, execução e acompanhamento de treinos.

## Stack

- React 18
- Vite 6
- JavaScript
- Lucide React

## Rodar

```bash
npm install
npm run dev
```

## Verificar

```bash
npm run verify
```

## Documentação

- `PRODUCT.md` — produto, escopo e regras;
- `AGENTS.md` — comandos e acordos para agentes;
- `docs/architecture.md` — fronteiras e direção de refatoração;
- `docs/design.md` — regras de interface;
- `docs/onboarding.md` — preparação local;
- `docs/quality.md` — checks;
- `docs/setup.md` — adoção do toolkit e pendências.

A API oficial é o serviço dedicado do Atlas. A URL pode ser sobrescrita por `VITE_API_URL`.
